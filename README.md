# Reconfigurable-Multi-Task-Collaborative-Robotic-Arm-with-Quick-Change-Gripper-System
A 4-DOF multi-purpose collaborative robot arm with a quick-change gripper coupling. Built with custom 3D-printed mechanics and modular electronics, it enables seamless switching of end-effectors for adaptable automation tasks.
